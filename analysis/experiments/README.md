# Experiment Analysis Script

This script automatically analyzes all JSON files in experiment run folders and generates comprehensive summary reports.

## Usage

```bash
# Analyze all experiments in the current experiments directory
node analyze-experiments.js

# Analyze experiments in a specific directory
node analyze-experiments.js /path/to/experiments
```

## What it does

The script will:

1. **Find Run Folders**: Scans for directories containing JSON files
2. **Analyze All File Types**: Automatically detects and analyzes different JSON file types:
   - **baseline-metrics-*.json**: Time-series simulation metrics (chi levels, coverage, movement, etc.)
   - **config-profile-*.json**: Optimized parameter configurations with descriptions
   - **optimized-config-*.json**: Optimizer state and convergence information
   - **essence-state-*.json**: Full simulation state snapshots
3. **Generate Reports**: Creates two comprehensive files in each run folder:
   - `analysis-summary.json` - Structured data for programmatic access
   - `analysis-summary.md` - Human-readable markdown report

## Supported File Types

### Baseline Metrics (`baseline-metrics-*.json`)
- Time-series snapshots of simulation performance
- Final state metrics (alive ratio, chi levels, coverage, etc.)
- Average metrics across the entire run
- Frontier exploration and movement patterns

### Config Profiles (`config-profile-*.json`)
- Optimized parameter sets for specific objectives
- Parameter descriptions and fitness scores
- Generation information and convergence status

### Optimized Configs (`optimized-config-*.json`)
- Evolutionary optimization results
- Generation number and best fitness achieved
- Target objective and convergence percentage

### Essence States (`essence-state-*.json`)
- Complete simulation snapshots
- World statistics (population, births, resources collected)
- Agent statistics (count, generations, energy levels)
- Resource statistics (vitality, depletion status)
- Individual agent details (position, velocity, lineage)

## Output Files

### analysis-summary.json
Contains structured data including:
- Run folder name and analysis timestamp
- Summary of all analyzed files by type
- Detailed metrics for each file type
- Complete metadata and configuration information

### analysis-summary.md
Human-readable report with:
- Overview of all analyzed files
- Section for each file type with key metrics
- Formatted tables and statistics
- Executive summary of experiment results

## Experiment Comparison

After analyzing individual runs, you can compare them using the comparison script:

```bash
# Compare all analyzed runs in the experiments directory
node compare-experiments.js

# Compare runs in a specific directory
node compare-experiments.js /path/to/experiments
```

The comparison script will:
- Find all `*analysis-summary.json` files (excluding the main comparison file)
- Compare key metrics across runs
- Show differences between experimental conditions
- Create `experiment-comparison.json` and `experiment-comparison.md`

### Comparison Metrics

The script compares:
- **Baseline Performance**: Chi energy, coverage, find rates, exploration metrics
- **Optimized Parameters**: All config parameters (decay rates, movement, sensing, etc.)
- **Optimization Results**: Generation count, fitness scores, convergence
- **Final State**: Agent counts, births, deaths, generations, resource collection
- **Lineage Analysis**: Family trees, lineage depth, orphan agents

### Comparison Output

- **experiment-comparison.json**: Structured comparison data
- **experiment-comparison.md**: Human-readable report showing differences between runs

## Directory Structure

The scripts expect a structure like:
```
experiments/
├── Ex01-111525/
│   ├── C run/
│   │   ├── essence-state-2025-11-16T05-30-27.json
│   │   ├── Crun-analysis-summary.json    ← Generated by analyze-experiments.js
│   │   └── Crun-analysis-summary.md      ← Generated by analyze-experiments.js
│   └── F run/
│       ├── essence-state-2025-11-16T05-15-46.json
│       ├── Frun-analysis-summary.json    ← Generated by analyze-experiments.js
│       └── Frun-analysis-summary.md      ← Generated by analyze-experiments.js
├── experiment-comparison.json           ← Generated by compare-experiments.js
└── experiment-comparison.md             ← Generated by compare-experiments.js
```

## Running the Script

From the project root:
```bash
node analysis/experiments/analyze-experiments.js
```

Or from the experiments directory:
```bash
cd analysis/experiments
node analyze-experiments.js
```
