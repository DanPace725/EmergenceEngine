# Experiment Execution Steps

## Baseline Collection
1. Refresh the page
2. Pause the simulation
3. Open the training panel
4. Click "Start Baseline" and unpause
5. Capture 40 snapshots
6. Pause the simulation
7. Export baseline metrics

## Optimization Run (F Objective)
8. Choose objective F
9. Click "Start" to begin optimization
10. Save the optimized configs
11. Click "Apply" to load the optimized configuration
12. Click "OK", then switch to "PLAY" mode
13. Click "Test" to run the optimized configuration
14. Run simulation for 10,000 ticks
15. Record screen capture
16. Export simulation state

## Optimization Run (C Objective)
17. Repeat steps 1-16, but choose objective C in step 8
